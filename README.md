# Expense Tracker

A responsive Expense Tracker web application built using HTML, CSS, and JavaScript.

## Features

### Core Features

- Add income transactions
- Add expense transactions
- Enter amount, category, date, and description
- Edit transactions
- Delete transactions
- Calculate total income
- Calculate total expenses
- Calculate current balance
- Filter transactions by type
- Filter transactions by category
- Persist transactions using Browser Local Storage
- Responsive design for desktop and mobile

### Bonus Features

- Monthly income summary
- Monthly expense summary
- Monthly balance
- Category-wise expense chart
- Form validation
- Helpful validation error messages
- Delete confirmation
- XSS-safe transaction rendering

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Browser Local Storage
- Chart.js
